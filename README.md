# Savings Manager

Track your savings balances across banks and brokers in GBP.

## Getting started
npm install
npm run dev

Then open http://localhost:3000 in your browser.

## Data storage

Your data is stored locally in the `data/` folder:

- `data/savings.csv` — all savings entries
- `data/settings.json` — currency settings

These files are created automatically on first run. Back them up if you would like to keep your data safe.
